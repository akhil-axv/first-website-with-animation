# DevFolio

A modern, responsive developer portfolio template built with HTML, CSS and vanilla JavaScript. Showcase an introduction, selected projects, skills and contact information.

## Features

- Responsive desktop and mobile layouts
- Modern dark theme with gradients and subtle animation
- About, projects, skills and contact sections
- Mobile navigation menu and active scroll navigation
- Accessible labels and reduced-motion support
- No frameworks, build tools or API keys required

## Run locally

1. Clone this repository:
   ```bash
   git clone https://github.com/akhil-axv/first-website-with-animation.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.

Alternatively, run `python -m http.server 8000` and visit `http://localhost:8000`.

## Personalize it

- Replace the sample name and introduction with your own.
- Replace sample project cards with real projects and working links.
- Update the skills to match your experience.
- Change `hello@example.com` to your preferred public contact email.

The project cards are sample concepts, not claims about completed work.

## Tech stack

HTML5 · CSS3 · Vanilla JavaScript

## Project structure

- `index.html` — page content
- `style.css` — responsive design
- `script.js` — navigation and scroll interactions
